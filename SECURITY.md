# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through this repository's GitHub Security Advisories feature. Do not include real Clay tokens, webhook URLs, CRM URLs, or customer records. Do not open a public issue for an unpatched vulnerability.

Include affected versions, impact, reproduction steps using sanitized data, and any suggested mitigation. Maintainers will acknowledge a complete report as soon as practical.

Only the latest released version is supported with security fixes.
