# Push Row store demo video

- Final export: `push-row-demo.mp4`
- Format: H.264 MP4, 1920x1080, silent
- Duration: 39.4 seconds
- Story: add a Clay destination, open Push Row on a LinkedIn profile, select the destination, and send
- Sources: the built Push Row extension, `assets/icon-source.svg`, and deterministic browser framing

Build the extension first, then run `npm run store:demo-video`. The capture script requires `ffmpeg`
on `PATH`, or its absolute path in `PUSHROW_FFMPEG`.
