Posthook

Privacy policy

Effective July 14, 2026

Local by design.

Posthook has no Posthook-operated server, account system, analytics, advertising, or telemetry.

Data handled

Posthook stores the destinations, optional authentication values, and routing rules you create in persistent Chrome extension storage on your device. That storage is private to trusted Posthook contexts, but it is not encrypted at rest.

When you click Send, Posthook derives source, URL, record ID, and object type from the active tab URL and sends those four fields to the Clay webhook you selected. Clay handles that request under its own terms and privacy practices.

Data not collected

Posthook does not collect page content, cookies, browsing history, send history, analytics, telemetry, or webhook response bodies. It does not sell or share data for advertising.

Your controls

You can edit or delete destinations and rules at any time. Delete all local data removes every Posthook setting and token and revokes the optional Clay host permission.

Permissions

Posthook uses activeTab after you invoke the toolbar action, storage for local settings, and optional access to api.clay.com only for a request you initiate.

Changes and contact

Material changes will be published with the extension and repository. Use the public repository for privacy questions without including secrets or personal data, and its private Security Advisories feature for vulnerabilities.
