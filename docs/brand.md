# Push Row brand system

## Identity

- Product name: **Push Row**
- Technical slug: `pushrow`
- Tagline: **CRM records to Clay, in one click.**
- Positioning: a focused Chrome utility for manually pushing URL-derived LinkedIn and CRM records to Clay tables.

Use **Push Row** with a space and title case in user-facing copy. Use `pushrow` only for package names, repository names, storage keys, message namespaces, and artifacts.

## Mark

The mark is three horizontal rows with the middle row moving right. Use the standalone mark without letters inside the icon. It must remain readable at the 16-pixel Chrome toolbar size.

The source of truth is `assets/icon-source.svg`. Run `npm run assets` after editing it; do not edit raster icons directly.

## Color and type

| Role      | Value     |
| --------- | --------- |
| Cobalt    | `#3157D5` |
| Navy ink  | `#172033` |
| Pale blue | `#E9EDFF` |
| Canvas    | `#F5F7FB` |
| White     | `#FFFFFF` |

Keep green and red reserved for success and destructive/error states. Use the native system sans-serif stack throughout the extension and collateral; do not add a web-font dependency.

## Voice

Write concise, literal copy centered on deliberate sends, Clay destinations, local storage, and URL-only record detection. Do not imply scraping, automatic sends, a hosted service, or support for destinations beyond Clay.
