# Chrome Web Store listing copy

## Short description

Send LinkedIn and CRM record URLs to your Clay tables in one deliberate click.

## Detailed description

Posthook turns the record open in Chrome into a clean Clay webhook payload. Add named Clay destinations, optionally create routing recommendations, then choose a table and send from the toolbar.

Supported pages:

- LinkedIn member profiles
- HubSpot CRM records
- Salesforce Lightning records
- Attio records

Posthook uses only the active page URL. It does not scrape page content, send automatically, keep history, run analytics, or use a Posthook server. Destinations, optional tokens, and rules stay in local Chrome extension storage.

## Single-purpose statement

Posthook's single purpose is to let a user manually send the URL-derived identity of an open LinkedIn or supported CRM record to a selected Clay webhook.

## Permission explanations

- `activeTab`: read the current URL after the toolbar action is clicked.
- `storage`: save destinations, optional authentication values, and routing rules locally.
- Optional `https://api.clay.com/*`: send the manual JSON POST to the selected Clay webhook.
