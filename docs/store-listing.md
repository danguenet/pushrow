# Chrome Web Store listing copy

## Short description

Push LinkedIn and CRM record URLs to your Clay tables in one deliberate click.

## Detailed description

Push Row turns the record open in Chrome into a clean Clay webhook payload. Add named Clay destinations, optionally create routing recommendations, then choose a table and send from the toolbar.

Supported pages:

- LinkedIn member profiles
- HubSpot CRM records
- Salesforce Lightning records
- Attio records

Push Row uses only the active page URL. It does not scrape page content, send automatically, run analytics, or use a Push Row server. Destinations, optional tokens, rules, and a configurable bounded activity log stay in local Chrome extension storage. Activity can be cleared or turned off and never includes webhook URLs or tokens.

## Single-purpose statement

Push Row's single purpose is to let a user manually send the URL-derived identity of an open LinkedIn or supported CRM record to a selected Clay webhook.

## Permission explanations

- `activeTab`: read the current URL after the toolbar action is clicked.
- `storage`: save destinations, optional authentication values, routing rules, and bounded activity locally.
- Optional `https://api.clay.com/*`: send the manual JSON POST to the selected Clay webhook.
