# Changelog

All notable changes to Push Row are documented in this file.

The project uses [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-07-27

### Added

- URL-only record detection for LinkedIn, HubSpot, Salesforce, and Attio.
- Multiple named Clay webhook destinations with optional authentication headers.
- Guided and regular-expression routing recommendations.
- User-initiated sends with a bounded, configurable local activity log.
- Local data management, permission revocation, and complete deletion controls.
- Chrome Manifest V3 packaging, automated checks, and release validation.
